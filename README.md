# Heat Haze

Heat Haze is a small C++ / OpenCV tool for manually reducing local heat-haze or air-distortion artifacts in photos.

The app opens an image, lets you mark the distorted edge with the mouse, detects the selected edge, fits a quadratic curve, and smooths the affected pixels.

## Important Files

- `Heat Haze.sln`: Visual Studio solution file.
- `Heat Haze/Heat Haze.vcxproj`: C++ project configuration, including OpenCV include and library paths.
- `Heat Haze/main.cpp`: Program entry point.
- `Heat Haze/WindowZoom.*`: OpenCV window, zooming, panning, mouse interaction, and undo support.
- `Heat Haze/method.*`: Edge detection and image repair logic.
- `Heat Haze/PolyFit.*`: Polynomial fitting for selected edge points.
- `Heat Haze/DSC_1744.jpg`: Default sample image.

## Requirements

- Windows
- Visual Studio 2022 with the C++ build tools
- OpenCV installed at `C:\Program Files\opencv\build`

If OpenCV is installed somewhere else, update the paths in:

- `Heat Haze/Heat Haze.vcxproj`
- `.vscode/tasks.json`
- `.vscode/launch.json`

## Run With Visual Studio

1. Open `Heat Haze.sln`.
2. Select the `x64` platform.
3. Build and run the project.

By default, the program opens `DSC_1744.jpg`. You can also pass an image path from the command line:

```powershell
.\x64\Debug\Heat Haze.exe "Heat Haze\DSC_2571.JPG"
```

## Run With VS Code

This repository includes VS Code configuration files:

- `Terminal -> Run Build Task`: builds `Debug x64`.
- `Run and Debug -> Debug Heat Haze`: builds and starts the debugger.
- `Terminal -> Run Task -> Run Debug`: builds and runs the app.

The VS Code tasks still call Visual Studio's MSBuild, so Visual Studio C++ tools must be installed.

## Controls

- Left-drag: mark the heat-haze or distorted edge region.
- Mouse wheel: zoom.
- Right-drag: pan after zooming.
- Middle-click: undo the previous edit (the last 10 edits are kept).

The processed image is written to `result.jpg`.

Intermediate debug images such as Canny, mask, and polynomial-fit outputs are disabled by default. To enable them, set `kSaveDebugImages` to `true` in `Heat Haze/method.cpp`.
